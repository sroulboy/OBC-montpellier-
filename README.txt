OBC — SITE VITRINE

Contenu :
- index.html : site vitrine responsive (ordinateur et mobile)
- assets/obc-logo.png : logo détouré à partir de l'image fournie

APERÇU EN LOCAL
Ouvrir index.html dans un navigateur. Une connexion internet est nécessaire pour charger la police Google Fonts ; le site reste lisible sans.

MISE EN LIGNE GRATUITE AVEC GITHUB PAGES
1. Crée un dépôt GitHub nommé par exemple obc-montpellier.
2. Ajoute index.html et le dossier assets (avec obc-logo.png) à la racine du dépôt.
3. Dans le dépôt : Settings > Pages.
4. Dans Build and deployment, choisis Deploy from a branch, puis la branche main et le dossier /(root), et sauvegarde.
5. GitHub affichera l'adresse publique du site après publication.

À PERSONNALISER AVANT PUBLICATION
- Le bouton Instagram est configuré vers le compte officiel OBC : https://www.instagram.com/onibosocrew/.
- Ajouter éventuellement les photos, le contact e-mail, les réseaux sociaux et les mentions légales de l'association.
